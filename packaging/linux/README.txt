Akshara Office for Linux
========================

Install (for your user only; no administrator password, no internet):

    tar xzf akshara-*-linux-x64.tar.gz
    cd akshara-*-linux-x64
    ./install.sh

Then start "Akshara Office" from the applications menu, or run `akshara`.
Remove it again with ./uninstall.sh (add --purge to also delete settings).

Requirements: a 64-bit Linux desktop with GTK 3, ALSA (libasound2) and OpenGL ES / EGL
(standard on Ubuntu, Debian, Fedora, Mint and most other desktops).

You can also run it without installing: ./bundle/akshara
